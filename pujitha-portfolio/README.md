# Pujitha Perumalla — GitHub Portfolio

A responsive personal portfolio website created from the information in Pujitha Perumalla's resume.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — mobile navigation

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `PujithaPerumalla.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your portfolio will be available at:
   `https://PujithaPerumalla.github.io/`

## Customize
Replace/add project links when the corresponding GitHub repositories are available. The resume does not provide individual project URLs, so this template intentionally does not invent them.
